# KP Fighter

Juego de lucha arcade para navegador protagonizado por **Sergio** y **Blotta**.

## Jugar

La versión publicada está disponible en:

**https://sebastiandc99.github.io/KPFighter/**

## Controles

- `A` / `D`: mover
- `W`: saltar
- `J`: golpe
- `K`: patada voladora
- `L`: poder especial
- `P`: pausa

En teléfonos y tablets aparecen controles táctiles. El juego funciona tanto en orientación vertical como horizontal.

## Personajes

- **Sergio:** panzazo, patada voladora y proyectiles de asado o fernet.
- **Blotta:** golpes de karate, patada voladora y energía de karate.

El rival es controlado por la máquina. Antes de cada combate Blotta lanza su desafío: “Te voy a echar”.
